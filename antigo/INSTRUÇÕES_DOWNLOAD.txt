═══════════════════════════════════════════════════════════════════
  COMO BAIXAR E USAR
═══════════════════════════════════════════════════════════════════

OPÇÃO 1: Baixar via GitHub (RECOMENDADO)
─────────────────────────────────────────
$ git clone git@github.com:GISC-TECH/destack-transport.git
$ cd destack-transport

⚠️ IMPORTANTE: Os backups do BD NÃO estão no GitHub (são muito grandes)
   Você precisa baixar a pasta backups/ separadamente do servidor!


OPÇÃO 2: Baixar pasta completa do servidor
───────────────────────────────────────────
No seu PC local, execute:

$ scp -r root@31.97.247.165:/root/apps/destack ./destack

Ou use WinSCP, FileZilla, etc.


═══════════════════════════════════════════════════════════════════
  BAIXAR APENAS OS BACKUPS DO BANCO
═══════════════════════════════════════════════════════════════════

Se já clonou do GitHub, baixe apenas os backups:

$ scp -r root@31.97.247.165:/root/apps/destack/backups ./destack/

Isso irá baixar ~172MB de backups do banco de dados.


═══════════════════════════════════════════════════════════════════
  DEPOIS DE BAIXAR - PRÓXIMOS PASSOS
═══════════════════════════════════════════════════════════════════

1. Instale o Docker Desktop
   - Windows/Mac: https://www.docker.com/products/docker-desktop
   
2. Abra terminal na pasta destack/

3. Execute:
   $ ./scripts/start-local.sh
   
4. Aguarde 1-2 minutos

5. Acesse: http://localhost:8001
   - Usuário: admin
   - Senha: admin123

6. (Opcional) Restaurar backup de produção:
   $ ./scripts/restore-backup.sh
